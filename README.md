# FaceUp

1. Загрузите содержимое этой папки на любой HTTPS-хостинг (например, GitHub Pages, Cloudflare Pages или Netlify).
2. Откройте адрес на Android в Chrome.
3. Разрешите доступ к камере, затем в меню Chrome выберите **«Установить приложение»**.

FaceUp показывает изображение без цифрового увеличения. Фронтальная камера отображается зеркально, задняя — без зеркалирования. Приложение сохраняет свою оболочку для работы без интернета, но при наличии сети всегда получает свежие файлы. Снимки сохраняются в хранилище FaceUp; из просмотра их можно скачать, отправить через системное меню Android или удалить.
